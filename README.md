# SoftwareLifeCycle

Local-deployable automotive software lifecycle governance platform for BMS / ECU software.

## V1 vertical slice

Supplier → Software → SSR → ASR → Component → Artifact Policy → Snapshot

Stack: Next.js + TypeScript, FastAPI + SQLAlchemy + Alembic, PostgreSQL, Docker Compose.

See `docs/baseline-v1.1.html` for the product baseline.
