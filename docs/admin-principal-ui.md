# 双语身份目录与精确详情

本包接入 API0.18.36 的私有身份读取，前端新增 /account/principals 和 /account/principals/{UUID}，默认中文，可切换English。账户页增加身份管理入口；身份注册结果可在新标签页打开原请求 UUID 的详情/历史，保留内存中的请求与回执。

## 读取行为

目录可按精确 principal_id、USER/SERVICE 和 ACTIVE/DISABLED 筛选，每页10条，保留筛选分页。直接读取身份表投影，新注册DISABLED、尚无授权身份也可查；不从名称、subject或授权行推断UUID。详情按规范化UUID独立请求详情和状态历史，保留两次读取的状态差异。history只覆盖PRINCIPAL_STATUS_CHANGED，不含注册、提供方历史或完整生命周期声明。原因最多500个Unicode码点，截断标志照实展示。

所有服务器读取先解密并复核当前token-bound会话，再向固定后台路径传递服务器token和session UUID。授权由后端检查，全球授权数不代表管理员资格。React仅接收白名单字段，显示名/原因按文本转义；原始subject、issuer、邮箱、token/cookie/审计payload不传至页面。当前read_only_mode来自新复核的身份，不信任目录或详情额外字段。

查询拒绝重复数组、未知项、非整数字符串、非法类型/状态/UUID或超出0–100000的offset。后端页元数据、行数、筛选匹配、唯一UUID、时间、布尔标记、精确history目标和coverage必须有效。目录响应最多16KiB，history最多32KiB，均限制声明与实际流；超限/失联/无效回执不展示部分目标或原始错误。允许API最大offset页正常读取；next_offset超出预算时隐藏下一页并提示缩小筛选，而不生成必然被拒的链接。count与数据也是独立SQL读取，并发变化导致元数据不一致时关闭展示、要求重试。

401要求重新登录，403提示管理员权限；只有明确principal_not_found的404显示身份不存在，旧API未注册路由等普通404显示信息不可用。启用读取前必须验证目标API已部署0.18.36；本包没有独立核验线上后端部署/版本。

## 状态与验收

管理员保护包括历史/暂停PLATFORM_ADMIN assignment；issuer匹配和保护只是读取快照，不代表批准提供方、可登录或可执行状态操作。当前页不提供激活/禁用写入。下一包实现冻结请求准备及独立默认关闭的受控发送，继续由后端复核保护、expected_status和实际会话撤销。

测试覆盖私有投影、后端拒绝、会话撤销、过滤/重复参数、空/末页/预算上限、精确详情/状态历史、独立快照、Unicode理由/响应大小、双语SSR和文本转义。CI还运行实际Next生产服务的zh/en禁用身份目录/详情SSR，验证200/no-store且无身份表单。模拟SSR不等于真实浏览器/管理员/OIDC验收；不重试此前被拒的站点访问。

公共演示只读、登录/提交通道默认关闭；内部服务器尚未安装。API代码0.18.36/schema0020不变，页面由67增至69；36/44=82%与七计划比例不提升。
