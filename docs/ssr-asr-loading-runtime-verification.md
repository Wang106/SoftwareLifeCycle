# SSR/ASR 加载时序与慢请求恢复验证

本包承接 PR #109 的加载提示实现及 PR #110 的证据收口。基线为
`bd627eb2303a59edb355e401b63c569d8e2551c4`。新增的是本地生产 HTTP/SSR
验证工具，不修改页面、API、数据库、权限或部署配置。

## 可重复执行

在仓库 `frontend` 目录依次运行：

```bash
npm ci
npm run build
node scripts/check-demo-loading.cjs
```

也可在既有 `npm run cf:build` 完成后运行。脚本必须使用实际 `.next/BUILD_ID`
对应的生产构建；不会用 `next dev` 或静态组件替身代替真实页面。
现有 CI 保持原样，本脚本不新增或替换 CI 门禁，需按上述命令显式执行。

脚本只启动绑定 `127.0.0.1` 的临时 HTTP API 和 `next start`，端口由系统分配。
Next 子进程使用白名单环境：API 地址覆盖为本地临时服务，认证关闭，遥测关闭，
不继承提供方凭据或真实提交配置。测试 API 只接受两个预期端点的 GET，拒绝身份
请求头及 Cookie。测试结束或失败时关闭子进程、连接和临时监听端口。
不会访问 Cloudflare、Render、业务数据库，不创建身份，不发送业务写命令。

## 实际检查矩阵

目标页面为 `/demo/zfi` 和 `/demo/releases`，各检查中文、English。
Cookie 仅设置本地页面的 `slc_language`，不会转发给测试 API。

| 情境 | 观察与断言 | 数量 |
| --- | --- | ---: |
| API 响应显式暂停 | 客户端收到实际 `<h1>` 加载提示时，API 尚未发送响应头；随后才释放 API，页面展示“样例未安装/不完整”的真实返回结果 | 4 |
| 请求头或 JSON 响应体不结束 | 使用页面现有的真实 15 秒期限，不替换定时器；加载提示先于期限出现，最终进入翻译后的不可用态 | 4 |
| 超时后再次 GET | 同一路径、同语言再次读取可获得新返回结果，不复用超时状态 | 4 |
| HTTP 503 | 展示不可用态及同页“重新读取”链接，不泄露上游错误正文 | 4 |
| HTTP 200 但 JSON 无效 | 同样明确不可用，不伪造 Snapshot 链接或不完整样例结果，不泄露原始正文 | 4 |

每个观察只允许一次预期 API GET，合计 20 次；不允许后台自动重试或保活。
四个超时案例交叉覆盖两页、两语言及请求头/响应体阻塞。
“重新读取”的验证是再次发起实际 HTTP GET，不是浏览器点击自动化。
只读成功响应使用显式 `sample_only=true, initialized=false` 的本地测试数据，
不冒充正式发布、审批结果或已经安装的 Excel 样例。

## 证据与解释边界

2026-10-23 首轮本地运行：20 项通过，20 次本地 API GET，约 61 秒。
四个真实超时观察约 15 秒后结束。日志逐项输出页面、语言、情境、加载提示到达时间
及响应完成时间；失败返回非零退出码。OpenNext构建后，最终脚本再次20/20通过、20次本地GET（约61秒）。完整前端1511项
通过，无失败/跳过；Next/OpenNext构建、禁用认证双语生产SSR和进度检查通过。
本地未执行完整后端/真实PG；远端CI仍须按最终精确head独立核验。

最强的加载时序证据是**先收到加载提示，再允许 API 发送响应**的因果关系。
日志毫秒数属于该机器、该构建与本地网络的一次观察，不是响应性能基准或 SLA。
超时的 14–23 秒容差用于判别真实 15 秒期限，整个 HTTP 请求有 25 秒安全上限；
机器严重繁忙时应先调查日志，不能放宽门禁来伪造成功。

本结果不证明浏览器绘制/水合时机，不证明 Cloudflare/OpenNext 在生产网络上不缓冲，
不证明 Render 冷启动、API 查询或用户网络已经变快。PR #108 用户的设备与双语功能
验收仍属于此前功能基线，不能代替此脚本的新运行证据。公共样例继续只读，免费方案、
真实身份、业务写入、内网部署和业务完成度均不变。
