## 可重复执行

在仓库 `frontend` 目录运行：

```bash
npm run build
node scripts/check-zfi-stage-runtime.cjs
```

脚本必须读取实际 `.next/BUILD_ID` 并启动 `next start`，不会用开发服务器或
组件替身代替生产路由。它仅绑定 `127.0.0.1` 的临时 API 和应用端口；Next
子进程使用白名单环境，认证与遥测关闭，不继承提供方凭据。临时 API 仅接受
`GET /api/v1/demo/zfi-import`，拒绝身份请求头、Cookie、其他路径和其他方法。
无论成功或失败，脚本都会关闭子进程、连接和监听端口。

## 解释边界

该工具验证当前代码构建出的本地 Next 生产路由，不是浏览器自动化，也不访问
Cloudflare、Render 或真实数据库。它不能证明当前冻结 Snapshot 绑定、人员权限、
正式发布、真实设备表现或公网时延。PR #108 的用户双语/手机/Windows 验收仍是
此前独立证据；本包不会扩大其范围。公共环境继续只读，OIDC、真实身份、业务写入
和内网部署仍关闭。
