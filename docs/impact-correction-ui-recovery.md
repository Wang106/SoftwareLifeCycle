## Manual format and read-only import

format=slc-impact-correction-recovery, version1, exact origin and the canonical operation/target/body/predecessor envelope. Maximum32768 UTF-8 bytes; strict field order and exact exported compact or two-space pretty JSON reject duplicate keys, unknown fields, noncanonical UUID/text/order, malformed Unicode, altered format/version/origin or credentials/success evidence. Origin is canonical HTTPS or HTTP local loopback. The original command must satisfy all slice A bounds.

Export requires a canonical confirmed review. Explicit clipboard copy and visible selectable text provide a fallback; no automatic storage/download/query occurs. It includes business data and is not proof of execution or an authenticated identity assertion.

Import performs zero network and stages unknown with a frozen facade exposing only state and recover; no send/retry method. The UI hides preparation/send/retry and permits only an explicit original audit query after sign-in. No import can replace an attempted controller. Import in a new component preserves original request bytes/ID; a missing/denied/mismatched audit remains unknown. Editable recovery text is not trusted evidence: the current principal and complete original audit still have to match.
