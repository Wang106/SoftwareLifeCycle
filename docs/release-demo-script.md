# SSR / ASR 云端只读演示脚本

第三轮：成功发布证据与阻断证据，约 12 分钟。该脚本用于测试样例；审批人、固件引用与审计均为合成记录。真实岗位授权、提交、交付、量产及公司内部部署不在此演示范围。

## 演示前提

前两轮代码已合并 PR56 / PR57。API 当前新增只读 `GET /api/v1/demo/release-evidence`，最多读取固定命名空间三个 Release，不扫描全站目录；计算使用原有 bounded Readiness，按实际当前 Snapshot UUID 查询，正式决策绑定独立展示。未安装样例返回 `initialized=false`；API 不可用时页面明确缺失，不提供静态成功替代。

第四轮需确认云端测试 API、数据库工作区和维护操作入口后才执行；本轮没有在提供方运行命令：

```bash
cd backend
python -m app.seed_release_demo --sample-only
python -m app.seed_release_evidence --sample-only
```

两者独立 opt-in，不接入启动 Seed。固定 UUID、调用方事务；重复运行保留已有审批/决策/执行/审计历史。不将命令用于公司数据库，不启用真实写入/OIDC，不输出数据库连接串。已有同 code 的外来产品会拒绝写入。检查健康状态、schema `0023_impact_withdrawal_history`、API 版本 `0.18.42` 与样例 API 返回后，再打开 `/demo/releases`。

## 验收与限制

桌面和移动端：中文/English 标题、节点、规则、关闭状态及缺失状态；文件 hash 长文本不溢出，表格可滚动；所有对象链接使用真实路由，DVP 使用条目 UUID 并固定 release_id/snapshot_no；不存在实际提交表单。API 不可用、未安装/不完整样例时无成功证据卡。

测试覆盖独立数据、旧历史不变、完整事务回滚、幂等 Seed、正反 Readiness、旧决策不匹配新快照、外来 Release 隔离、已有 Passport 与新只读 API 一致；真实 PostgreSQL 追加历史触发器与回滚/重复由既有完整 CI 执行。本机没有 PostgreSQL，不把 SQLite 当数据库触发器验收。

当前 Readiness 的 Verification 规则检查执行覆盖，不保证 FAIL 结果必定单独阻断；本演示仅证明“当前快照未执行”被阻断，不把它描述成已完成所有失败结果门控。未替换原规则/放宽门控。浏览器截图、提供方 API/schema 与实际样例安装均由第四轮独立验收；构建通过不能替代线上数据验收。

## 第四轮：Excel 总览筛选与逐项核对（2026-10-13）

`/demo/zfi` 是 PR60 导入的 Excel 家族；`/demo/releases` 是独立合成发布证据家族。两者不能混用为 Excel 版本真实测试证据。上文 schema0023/API0.18.42 是第三轮历史基线；当前代码 required head 为0024_release_customer_scope/API0.18.43。线上状态仍须现场读取，不根据本脚本推定。

1. 正常打开总览，分别切换中文和English；确认完整家族统计、导入回执与各行当前状态。不能按历史固定15/3/1/1计数判断当前状态。
2. 点击发布类型、客户、审批状态组合；顶部保持完整家族计数，下方明确匹配记录数。STANDARD+客户若无交集，应显示无匹配，不显示其他客户来补位。
3. 每页最多10条；默认20行样例分两页。翻页保留筛选；更改筛选回到第一页；清除筛选恢复完整列表。确认所有原UUID恰好各出现一次，同版本KUBO/VOL分别进入自己的ASR。
4. 沿每行版本/审批链接核对原客户、项目、源日期、四级节点状态；合成审批不代表实际人员审批，APPROVED不代表正式RELEASE。
5. 在手机宽度下核对筛选链接换行、选中状态/键盘焦点、表格横向滚动及最后一列文件/测试数；在桌面核对分页与返回链接。
6. API不可用/外来/不完整家族不应显示成功列表或筛选分页；零匹配是筛选结果，不能当作导入缺失。Excel缺少组件/固件/测试时仍展示原缺失，不从独立合成家族补造。

上述浏览器检查尚未完成；既往403/1010阻碍必须解除后由正常授权访问验收，不绕过。SSR/React渲染回归和生产构建通过仅是代码证据，不是桌面/手机现场验收。

## 第四轮：文字检索（2026-10-13）

总览使用固定本站GET检索，不调用业务命令。输入版本、Excel编号、软件、客户、项目、发布UUID或审批编号；大小写不敏感，各空白分隔关键词都必须在这些字段中匹配，原始证据不改。

1. 输入 `v3.8.1.1`、`ASR01` 或一个原项目编号；确认匹配行的UUID/审批链接和全家族统计。两个客户同版本仍为独立记录。
2. 输入 `KUBO v3.8.1.1`，再组合客户/类型/审批状态；冲突关键词/筛选显示零匹配，不退回完整家族。清除筛选同时移除关键词。
3. 键盘Enter或搜索按钮通过GET提交，保留三个筛选并回到第一页；翻页及筛选链接保留关键词。分享或刷新当前URL应恢复同一查询。
4. 中文/English核对label、帮助说明、按钮、焦点和手机换行。检索词为普通文字，URL编码或HTML字符不变为外站目标或脚本。

169项本地SSR/本地化回归为代码证据；真实浏览器仍未验收。后端数据可能变化，不把某次检索计数固定为现场成功标准。
