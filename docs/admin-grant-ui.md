# 双语管理员授权目录 UI — 2026-10-08
模式：Codex。页面 /account/grants，账户页提供入口。
本包只实现管理员读取，不提交新增/暂停/恢复操作。GLOBAL/PROJECT/SOFTWARE 范围与 ACTIVE/SUSPENDED 筛选；每页10条，展示精确授权、身份和目标UUID，总数及上下页；改变筛选回到第一页。
使用既有服务器端加密会话。每次先复核真实后端会话，再请求管理员目录，由后端重新判定 PLATFORM_ADMIN。全局角色数量不当成管理员证明。Bearer 与 session ID 仅在 server-only 请求中使用，绝不传给 React/浏览器。上游JSON经字段投影，限16KiB流式响应、5秒超时、no-store且禁止重定向。过大/无效响应显示不可用。
默认中文及English遵循现有语言选择器。未配置、会话失效、权限拒绝、无效筛选、空结果、服务故障分别显示。用户名称由React转义；界面文字翻译不改变请求枚举或UUID。offset分页不是固定时间导出，也不代表无限规模浏览。
回归新增5个测试，覆盖凭据仅转发、字段投影、后端拒绝、筛选边界、撤销会话和无效目录。完整前端/构建需在GitHub Actions执行；本地尚未安装项目依赖，不能声称本地前端测试通过。
后续：精确授权详情与状态历史、受控状态变更确认、创建授权/身份表单；真实提供方/管理员验收。当前身份管理里程碑仍不完整，所有进度不变。
